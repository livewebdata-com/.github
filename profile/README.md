# Live Web Data

How fresh is the web your AI reads? Live data, explained plainly.

- **Website:** [livewebdata.com](https://livewebdata.com)
- **Blog:** [livewebdata.com/blog](https://livewebdata.com/blog) · **Guides:** [livewebdata.com/guides](https://livewebdata.com/guides)
- **Docs:** [livewebdata.com/docs](https://livewebdata.com/docs)
- **CLI:** [`livewebdata`](https://github.com/livewebdata-com/cli), live web pages as Markdown from your terminal ([docs](https://livewebdata.com/docs/cli), [npm](https://www.npmjs.com/package/@livewebdata-com/cli))

```bash
npx @livewebdata-com/cli fetch https://example.com -o text
```
